# SAYLIV 🚢

## Intelligent Freight Forecasting & Vessel Chartering Decision Support System

SAYLIV is an intelligent decision-support prototype for freight forecasting, vessel selection, port compatibility, risk assessment and voyage planning.

### 🌐 Live Prototype
https://sayliv-2007-1.onrender.com

### ⚙️ Backend API

### 🚀 Key Modules
- Freight Forecasting
- Vessel Optimization
- Port Compatibility
- Risk & Idle-Time Analysis
- Freight Pooling
- Carbon-Aware Planning
- End-To-End Transport Planning
- What-If Simulator
- Ocean Scanner
- Voyage Planner
- Weather Consideration
- Cargo Booking
